# 数码资产持有成本管理系统

一个用于记录数码产品购入、计算每日持有成本、登记出售/损坏并分析折旧的桌面小工具。

## 快速开始

双击运行 `dist/数码资产持有成本管理.exe`，会自动在浏览器打开（地址 `http://127.0.0.1:5678`）。
首次运行会在 exe 同级目录生成 `asset_tracker.db`（SQLite 数据库），所有数据都存在这里。

> 提示：如果浏览器没有自动弹出，手动访问 http://127.0.0.1:5678 即可。

## 功能

### 资产管理
1. **录入资产**：名称、品牌、分类、购买价格、购买时间、配置，支持任意「自定义选项」（字段名+值）。
2. **每日持有成本**：`购买价格 ÷ 已持有天数`，列表实时显示。
3. **登记出售 / 损坏**：
   - 已售出：填写处理日期 + 出售价格，系统计算 **最终持有成本 =（购买价 − 出售价）÷ 持有天数**，以及 **折旧 = 购买价 − 出售价** 与折旧率。
   - 已损坏：视为全额损失，最终持有成本 = 购买价 ÷ 持有天数。
   - 已处理的资产可随时「恢复」为使用中。
4. **强大表格**：
   - 列排序（点击表头切换升/降序）
   - 多条件筛选（状态 / 品牌 / 分类 / 关键词）
   - 汇总行（当前筛选结果的总投入、每日成本合计、盈亏合计）
   - 行展开详情（配置、自定义字段、备注、折旧明细）
   - 右侧抽屉式录入表单，表格全宽显示

### 报表分析
- **统计卡片**：资产总数、持有总额、总投入、总盈亏、当前每日成本、累计折旧
- **趣味排行榜**：败家之王、最强钉子户、跳水冠军、性价比之王
- **智能洞察**：自动生成品牌集中度、折旧警示、持有习惯、成本感知、盈亏总结
- **6 大图表**：
  - 每日持有成本排名（柱状图）
  - 资产折旧排行（含折旧率、最终持有成本）
  - 品牌投入分布（环形图）
  - 分类投入分布（玫瑰图）
  - 月度投入趋势（渐变柱状图）
  - 资产画像散点图（持有天数 vs 每日成本，点大小=价格）

## 技术架构
- 后端：Python + Flask
- 数据库：SQLite（持久化，文件随 exe 携带）
- 前端：原生 HTML/CSS/JS + ECharts 图表
- 打包：PyInstaller（onefile，免安装 Python 环境）

## 目录结构
```
asset_tracker/
├── app.py                  # Flask 后端 + SQLite + 成本计算
├── build.py                # PyInstaller 打包逻辑
├── build.bat               # 一键打包脚本（双击运行）
├── requirements.txt        # 依赖
├── .gitignore              # Git 忽略规则
├── templates/
│   └── index.html          # 页面
├── static/
│   ├── css/style.css       # 样式
│   └── js/
│       ├── app.js          # 前端逻辑
│       └── echarts.min.js  # 图表库（离线可用）
├── dist/                   # 打包产物（exe 在此）
│   └── 数码资产持有成本管理.exe
├── Dockerfile              # Docker 部署
├── docker-compose.yml
└── DOCKER.md
```

## 重新打包

### 方式一：双击脚本（推荐）
双击 `build.bat`，脚本会自动完成：检查 Python → 安装依赖 → 清理旧构建 → 执行打包 → 显示产物位置。

### 方式二：命令行
```
pip install -r requirements.txt
python build.py
```

产物在 `dist/数码资产持有成本管理.exe`。

## 开发模式

直接运行 Python 源码：
```
python app.py
```
服务启动在 http://127.0.0.1:5678，支持 Ctrl+C 优雅退出。

## Docker 部署

详见 `DOCKER.md`。

## 说明
- 数据仅保存在本地 `asset_tracker.db`，删除该文件即清空所有记录。
- 服务固定监听本机 `127.0.0.1:5678`，不对外网开放。
- 启动时会自动检测端口占用，如旧进程未退出会自动清理。
